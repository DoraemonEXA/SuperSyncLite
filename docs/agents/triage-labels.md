# Triage labels

Use these values on a local ticket’s `Status:` line during triage.

| Status | When to use it |
| --- | --- |
| `needs-triage` | The owner needs to evaluate the request. |
| `needs-info` | The reporter needs to supply more information. |
| `ready-for-agent` | An agent has enough detail to implement the ticket. |
| `ready-for-human` | The work requires human judgment, access, or action. |
| `wontfix` | The owner has decided to close the request without implementing it. |
