# SuperSync Lite

SuperSync Lite lets each user synchronize their Super Productivity data across their own devices.

## Language

**User**

A person with a manually provisioned account and a private sync dataset.

**Administrator**

The role responsible for provisioning user accounts and handing each user their authenticator enrollment QR code.

**Dataset**

The Super Productivity data belonging to one user, shared across that user's devices.

**Enrollment QR code**

A code a user scans to set up the authenticator that generates their sign-in codes.
